# Samuel

<img src="assets/icon.png" alt="Samuel 应用图标" width="160">

**一个轻量的 Windows 任务栏信息条，让网络状态与关注的行情常伴左右。**

[![Windows](https://img.shields.io/badge/Windows-10%20%2F%2011-0078D4)](https://github.com/hrthas-king/Samuel/releases/latest)
![Go](https://img.shields.io/badge/Go-1.24%2B-00ADD8)
![License](https://img.shields.io/badge/license-MIT-blue)
[![CI](https://github.com/hrthas-king/Samuel/actions/workflows/ci.yml/badge.svg)](https://github.com/hrthas-king/Samuel/actions/workflows/ci.yml)

Samuel 原名 PulseBar，将网络感知与双标的行情显示组合在一条透明悬浮条中。它使用 Windows 原生界面和 Go 标准库，无需单独安装运行时。应用运行后可从任务栏最左侧查看信息，也可通过系统托盘打开菜单。

> **关于名字**
>
> Samuel 致敬电报先驱 Samuel F. B. Morse。1844 年，他从华盛顿向巴尔的摩的 Alfred Vail 发送了著名电报，展示了电信号跨越距离传递信息的可能。Morse 的工作也建立在 Vail、Leonard Gale、Joseph Henry 等人的贡献之上。我们借用这一名字，向让信息跨越距离的探索致意。资料：[美国国会图书馆](https://www.loc.gov/item/mmorse000107/)、[史密森尼学会档案](https://siarchives.si.edu/sites/default/files/pdfs/jhpp/JHP_Inventor_of_the_Telegraph.pdf)。

## 下载安装

1. 打开 [GitHub Releases](https://github.com/hrthas-king/Samuel/releases/latest)，下载适合设备的 Windows 压缩包：大多数 PC 选择 **amd64**，Windows ARM 设备选择 **arm64**。
2. 如果正在运行旧版 PulseBar，先在其托盘菜单中退出。解压后运行 `Samuel.exe`；程序启动后显示任务栏悬浮条和系统托盘图标。
3. 右键托盘图标打开菜单；需要固定开机运行时，在菜单中启用 **开机自启**。

如果托盘图标被 Windows 收纳到隐藏图标区域，点击任务栏右侧的上箭头即可找到。版本、构建和验证范围见 [更新记录](docs/CHANGELOG.md) 与 [验证记录](docs/VALIDATION.md)。

## 界面与操作

悬浮条分为网络和行情两部分：

```text
● US  ↑↓                     ● VOO  699.48  +0.13%  |  ● QQQ  704.35  -0.01%
● US  ↑12K  ↓1.5M  18ms      ● VOO  699.48  +0.13%  |  ● QQQ  704.35  -0.01%
```

左侧显示出口地区、连通性和流量活动；在菜单勾选 **任务栏显示实时网速与延迟** 后，可展开上下行速率和 HTTPS 请求延迟。右侧显示当前组合中两个标的的名称、价格和涨跌幅；彩色状态表示交易时段，异常时可悬停查看原因和行情时间。以上数字仅是界面示例。

网络状态灯：**绿色正常、黄色待确认、红色断网警告、灰色检测中**。行情标记分别表示**黄色太阳为盘前、绿色为盘中、蓝色为盘后、紫色月牙为夜盘、灰色为休市**；行情异常时还会显示 `!`。

**个股美元市值：**当组合包含个股时，该股票报价下方显示一行总市值，例如 `市值 $5.16T`，随行情轮询更新。金额统一为美元，`K / M / B / T` 分别表示千 / 百万 / 十亿 / 万亿。ETF、指数与期货不显示公司市值，混合组合只在个股一侧显示。

美股使用 Yahoo Finance 常规主报价及其公司总市值，保持价格与市值口径对应，避免将多股类公司的一类股数误当作公司总股数。A 股使用腾讯总市值并按 USD/CNY 报价折算，汇率通常每分钟复核；折算金额带 `≈`，悬停可查看来源、汇率和汇率时间。市值或汇率缺失时显示 `市值 --`，价格仍可正常显示。市值、股本和汇率各有上游更新时间，轮询不保证逐笔或零延迟。

<img src="assets/capitalization-stocks.png" alt="个股报价下方显示美元总市值的原生绘制示例" width="640">

**指数估值：**指数报价下方显示 PE、PB，括号中分别是该指标的历史百分位，例如 `PE 27.04(23.5%)  PB 8.65(60.0%)`。默认在该指标最新统计日向前取近 10 年、同一指数、同一来源的有效历史样本，计算不高于当前值的样本比例；历史不足 10 年时使用实际区间，少于 30 个有效样本不计算分位。悬停可查看来源、数据日期、实际区间和样本数。估值按来源的日/周频统计，后台定期复核，与报价刷新独立。

当前接入情况如下；缺失值统一显示 `--`，不会使用全国市场、其他指数或跟踪 ETF 的数据替代：

| 指数 | 可核实的估值数据 |
| --- | --- |
| 纳斯达克100 / 标普500 / 德国DAX | 股叉叉公布的同指数 PE-TTM、PB 历史序列，程序按近10年重新计算各自百分位 |
| 上证 / 深证成指 | 腾讯同指数当前 PE；当前来源的 PB 和可核实历史缺项显示 `--` |
| 日经225 / 韩国综合 / 法国CAC40 | 暂未接入符合上述口径的可自动读取数据，估值项显示 `--`，报价正常显示 |
| 恒生 / 创业板 | 同指数历史序列可用时显示 PE、PB 和分位；其他缺项同样显示 `--` |

历史来源：[股叉叉指数估值及口径说明](https://guchacha.com/index-valuation)。该来源将日经和 CAC40 的部分数据列为全国市场近似，因此 Samuel 不采用这些代理数据。分位窗口与来源默认的“上市以来”可能不同，具体以悬停所示区间为准。估值用于展示，不提供买卖判断。

<img src="assets/valuation-indices.png" alt="指数 PE PB 及各自历史百分位的原生绘制示例，数值仅作布局演示" width="640">

*图为原生布局示例；估值统计日期、实际历史区间及当前数值以悬停数据为准。*

右键菜单提供刷新、锁定位置、恢复到任务栏左侧、涨跌配色、行情组合、显示大小、刷新间隔、诊断、自启和退出。解锁后可拖动悬浮条；锁定后悬浮条支持鼠标穿透，可继续从托盘打开菜单。显示大小支持 75%、85%、90%、100%、115% 和 130%，显示刷新间隔可选 1、2 或 5 秒。

**托盘图标可选：**在右键菜单打开 **托盘图标**，可选择 **Samuel 应用图标**（默认，霓虹 S 图案）或 **网络状态图标（地区 / 上下行）**。选择立即生效并自动保存，重启后保持；两种图标都可悬停查看网络与行情、右键打开菜单。透明行情条的显示独立于这一选项。

菜单与自定义组合面板支持系统深浅色、键盘操作和高 DPI；菜单长列表可用滚轮或方向键浏览。系统启用高对比度或报告屏幕阅读器开启时，菜单回退至 Windows 原生菜单。

<img src="assets/fluent-input-dark.png" alt="深色自定义组合面板预览" width="400"> <img src="assets/fluent-input-light.png" alt="浅色自定义组合面板预览" width="400">

## 网络状态

- **出口与连通性**：显示公网出口的国家或地区代码和状态灯；应用会结合心跳、网络变化与有效通信证据判断连接状态。
- **速率**：读取单一出口网卡的收发字节，计算上行与下行速率。遇到 TUN / VPN 虚拟路由时，按可用的非隧道默认路由选择底层网卡，避免部分虚拟网卡将同一流量计入两个方向，也不叠加虚拟和物理接口。统计包含该网卡的全部流量；显示值是采样间隔内的速率，不是带宽测速结果。无法找到可用接口时显示 `--`，诊断中可查看统计网卡及错误。
- **延迟**：每 5 秒通过系统网络环境向 Cloudflare 发起一次独立 HTTPS GET，测量从发送请求到收到响应头的耗时，包含连接与 TLS 等过程。失败或数据超过 15 秒未更新时显示 `--`。这一数值是到测量目标的请求耗时，不代表所有网站或游戏的延迟。
- **代理切换**：检测路由、地址及常见代理连接的变化，并重新核实出口；网络路径切换期间状态可能短暂显示为待确认。

悬停或打开 **查看详细诊断信息** 可检查数据源、采样时间与错误原因。网络诊断可能包含公网 IP，请在分享前自行检查内容。

## 行情组合

菜单中直接显示当前组合，展开 **More（更多行情）** 可切换其他组合。内置十一组：

| 组合 | 标的 |
| --- | --- |
| 标普 / 纳指 ETF | VOO / QQQ（默认） |
| 半导体 ETF | SOXX / SMH |
| 美股市值前二（2026-10-29 核对） | NVIDIA / Apple（NVDA / AAPL） |
| 商品 | 黄金 / 布伦特原油 |
| A 股指数 | 上证指数 / 创业板指数 |
| 港股指数 | 恒生指数 / 恒生科技指数 |
| 日韩指数（腾讯） | 日经 225 / 韩国综合指数 |
| 欧洲指数（Yahoo） | 法国 CAC 40 / 德国 DAX |
| 国内场内 ETF | 华安纳指 ETF / 华夏标普 500 ETF（159632 / 159655） |
| 美股指数 | 纳斯达克100 / 标普500（^NDX / ^GSPC，指数本身） |
| 沪深指数 | 上证 / 深证成指（000001 / 399001），原有创业板组合保留 |

**统一报价口径：**美股（含纳指100、标普500及美国 ETF）和欧洲指数固定使用 Yahoo Finance；中国市场（含港股）与日韩固定使用腾讯财经。商品继续使用腾讯既有期货接口。来源失败时不跨站切换。

美股默认对齐 Yahoo 常规主报价：常规价格、涨跌额及当日涨跌幅成组使用，盘前、盘后分段报价不覆盖主数字。市场状态灯表示当前时段；悬停另列出报价日期、涨跌基准和来源。常规前收优先采用来源字段，缺失时才由同组涨跌额反推，备用接口不把区间起点混作涨跌基准。个股显示美元市值，指数显示估值，基金与 ETF 不增加这些字段。

**VOO / QQQ 夜盘：**美东周日至周四 20:00 至次日 04:00，这两只 ETF 自动显示 Yahoo 的夜盘价格、夜盘涨跌幅与对应成交时间，涨跌基准是最近一次常规收盘，不混入包含上一常规交易日的全天涨幅。纽约时区规则自动处理冬夏令时；04:00 后恢复常规主报价口径。仅接受本次夜盘内、时间合理且价格与涨跌额/幅一致的源数据。夜盘字段缺失、时间过期或校验不通过时，显示灰色状态和最近常规收盘，悬停明确提示“夜盘数据不可用”；图表备用接口没有可核实的夜盘时间，不将其全天价当作夜盘。Yahoo 的[夜盘说明](https://uk.finance.yahoo.com/quote/VOO/)注明该交易来自 Blue Ocean ATS；行情轮询与最近成交时间分别展示，不承诺逐笔或零延迟。

“美股市值前二”是按菜单注明日期核对的固定组合，依据 [Stock Analysis](https://stockanalysis.com/list/largest-us-companies/) 与 [CompaniesMarketCap](https://companiesmarketcap.com/usa/largest-companies-in-the-usa-by-market-cap/) 的公司市值榜单配置；行情持续刷新，市值排名变化时需重新核对组合。

可显示盘前、盘中、盘后、夜盘和休市状态；可用时段由标的与数据源决定。国内场内 ETF 按上市交易所的交易时段成交，价格显示三位小数；休市、停牌或没有新成交时，可能保留上一笔报价。

**欧洲与日韩指数：**欧洲使用 Yahoo 的 `^FCHI / ^GDAXI` 常规报价，日韩使用腾讯的 `gzN225 / gzKS11`。不同站点的时效、前收或复核数值可能略有不同，核对时应同时匹配来源、统计日期和时段。指数在盘中明显较旧时保留延迟提示，休市后不会把收盘报价年龄当成盘中延迟。

### 自定义股票与 ETF

1. 打开 **More → 其他（自定义股票 / ETF）→ + 新增组合**。
2. 分别输入两个不同的代码，例如 `513100` 与 `513500`、`AAPL` 与 `MSFT`，或国内 ETF `513500` 与美股 `AAPL`。
3. 按 **Enter** 或点击 **添加并显示**。程序联网核对代码；成功后立即保存并切换，失败时在面板中显示原因。

国内标的输入六位数字，程序按 `5/6` 沪市、`0/1/3` 深市、`4/8/92` 北交所匹配后联网校验；美股输入字母代码，大小写自动统一，`BRK.B` 与 `BRK-B` 按同一代码处理。已保存组合列在 **其他** 子菜单中，可直接切换，也可使用旁侧删除按钮；删除当前组合后回到默认组。点击面板外、按 **Esc** 或点击 **取消** 可关闭输入面板。

**行情时效：**报价来源按上述市场规则锁定，仍受来源、交易所和网络环境的可用性与时效影响。刷新按菜单选择的 1 / 2 / 5 秒轮询，不能消除上游延迟；绿色时段标记表示盘中，不代表零延迟。悬停提示和诊断可查看来源、行情时间及涨跌基准。本工具用于信息展示，不执行交易。

## 设置与隐私

设置与自定义组合保存在本机 JSON，包含界面位置、大小、刷新间隔和行情选择。开机自启由当前用户的 Windows 设置管理。公网出口查询与 HTTPS 延迟测量使用 Cloudflare，报价查询使用腾讯财经或 Yahoo Finance，已接入的指数估值历史读取股叉叉公开接口；各服务可见正常请求所需的网络信息。配置文件不保存公网 IP 或历史流量。

从 PulseBar 升级时，Samuel 默认继续使用原来的 `%LOCALAPPDATA%\PulseBar\config.json`，因此可以读取已有设置和组合。可通过 `SAMUEL_CONFIG` 环境变量指定配置文件；旧变量 `PULSEBAR_CONFIG` 也兼容，二者同时设置时以前者为准。

如果旧版的开机自启指向与 `Samuel.exe` **同一目录**下、且不带参数的 `PulseBar.exe`，新程序启动时会自动更新自启路径。其他旧路径不会自动更改；请在 Samuel 的托盘菜单中关闭后重新启用 **开机自启**，以指向新程序。

## 从源码构建

需要 Windows 10 / 11、Go 1.24 或更新版本，以及 Git。运行时无需额外依赖。

```powershell
git clone https://github.com/hrthas-king/Samuel.git
cd Samuel
./scripts/verify.ps1
./scripts/build.ps1 -Arch amd64 -Version v1.0.11
```

构建脚本输出 `dist/Samuel-windows-amd64.exe`；ARM 设备可将 `-Arch amd64` 改为 `-Arch arm64`。`verify.ps1` 包含自动测试、静态检查、格式检查与双架构构建。也可以创建包含文档的发布压缩包：

```powershell
./scripts/package.ps1 -Version v1.0.11
```

常用命令（在可执行文件所在目录运行）：

```powershell
./Samuel.exe --version       # 显示版本
./Samuel.exe --dock-left     # 将运行中的悬浮条移回任务栏左侧
./Samuel.exe --diagnostics   # 打开诊断窗口
./Samuel.exe --probe         # 运行一次网络与行情诊断
./Samuel.exe --quit          # 请求当前实例退出
```

源码位于 [`internal/`](internal/)，构建与打包脚本位于 [`scripts/`](scripts/)；架构说明、历史版本和验证结果在 [`docs/`](docs/)。
